# Customer Shopping Behavior Analysis

## 📌 Overview

This project analyzes customer shopping behavior using **Python, MySQL, and Power BI**.

The project follows an end-to-end data analytics workflow, starting with dataset loading and exploratory data analysis in Python, followed by data cleaning, SQL-based analysis in MySQL, and the creation of an interactive Power BI dashboard.

The goal is to identify **customer trends, purchasing patterns, product performance, and key business insights** from the dataset.

---

## 📂 Dataset

The project uses a customer shopping behavior dataset containing information such as:

* Customer demographics
* Product categories
* Purchase information
* Purchase amount
* Review ratings
* Discounts and subscriptions
* Shipping preferences
* Payment methods
* Shopping frequency

The dataset was initially loaded into Python for exploration and cleaning before being analyzed using MySQL.

## 🔄 Project Workflow

### 1. Load Dataset

* Imported the dataset into Python using Pandas.
* Examined the structure, columns, data types, and dataset size.
* Checked for missing and duplicate values.

### 2. Exploratory Data Analysis

Performed EDA in Jupyter Notebook to understand:

* Customer demographics
* Product categories
* Purchase behavior
* Spending patterns
* Review ratings
* Subscription behavior
* Payment methods
* Shopping frequency

### 3. Data Cleaning

Cleaned and prepared the dataset for analysis by:

* Handling missing values
* Removing duplicate records
* Correcting data types
* Standardizing column values
* Creating derived columns where required
* Preparing the cleaned dataset for database analysis

### 4. MySQL Analysis

Loaded the cleaned data into **MySQL** and performed SQL analysis using:

* SELECT statements
* Filtering and sorting
* GROUP BY and aggregations
* CASE statements
* JOIN operations
* Subqueries
* Common Table Expressions (CTEs)
* Window functions

The SQL analysis was used to identify important customer and business trends.

### 5. Power BI Dashboard

The analyzed data was connected to Power BI to create an interactive dashboard.

The dashboard presents important KPIs and visualizations to make the analysis easier to understand and support data-driven decision-making.

 📈 Key Results & Insights

The analysis helps identify:
